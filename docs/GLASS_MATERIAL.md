# 主站玻璃材质

主站恢复到引入 RhineLabUI 之前的布局，保留服务端索引快照、正文按篇加载、
详情缓存、共享滚动调度和按需加载的 Canvas 场景。

## 折射

`LiquidGlassLens` 只为导航、阅读页顶栏和浏览进度条准备折射。
位移图根据实际宽高与圆角生成，单位为 CSS 像素，最多 768 × 128、65,536 像素。
只有边缘 8–16px 的圆弧区域产生位移，中心为中性向量，位移不超过 7px。
滤镜直接施加在玻璃表面上，不放进被父背景隔离的内层装饰；正文和按钮文字保持清晰。

尺寸变化使用 100ms 合并更新，最多缓存 12 组位移图。
鼠标移动不生成位移图；嵌套按钮不叠加背景滤镜。
较大的搜索面板使用原生模糊和边缘高光，文章卡片不再常驻背景模糊。
打开搜索或图片预览时保留背景最后一帧并暂停首屏场景，避免在遮罩后持续绘制。

增强路径目前限于项目验证过的 Chromium 浏览器，并检查滤镜语法支持。
移动端、降低透明度、高对比度设置和其他浏览器保留原生材质。
主题切换期间临时使用原生低半径模糊，降低同一帧内的合成压力。

## 高光

所有玻璃使用一套委托式指针监听，最多每个动画帧更新一次。
先批量读取位置，再写入高光坐标；按钮与外层导航一起跟随。
离开后仅改变透明度，不把坐标重置到中心。
